# Portfólio — Eduardo Souza

Site pessoal estático em HTML, CSS e JavaScript, sem dependências de build. O
portfólio apresenta competências de QA e automação, com detalhes de configuração
dos projetos Playwright/BDD e Cypress.

## Projetos em destaque

- [Musi Playwright BDD](https://github.com/dudutronic/musica-ae-qa): TypeScript,
  Cucumber/Gherkin, execução isolada, evidências e CI.
- [Musi Cypress E2E](https://github.com/dudutronic/musica-ae-qa-cypress):
  validação de fluxos, responsividade, evidências e CI.

## Publicação no GitHub Pages

Este site está preparado para o repositório `dudutronic.github.io`.

1. Envie o conteúdo desta pasta para a raiz da branch `main` desse repositório.
2. Em **Settings → Pages**, selecione **GitHub Actions** como fonte de publicação.
3. O workflow em `.github/workflows/pages.yml` publica o site após cada push.

Quando o deploy terminar, o site estará disponível em <https://dudutronic.github.io>.
