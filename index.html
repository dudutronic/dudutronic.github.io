AUTOMAÇÃO DE TESTES · PROJETO EM DESTAQUE ↗ PESSOAL

Musi Playwright BDD

Uma suíte de testes end-to-end que combina Playwright, TypeScript e Cucumber para validar fluxos com cenários legíveis, relatórios com evidências e execução automatizada no GitHub Actions.

TypeScript Playwright Cucumber BDD CI / GitHub Actions

COMO O PLAYWRIGHT FOI CONFIGURADO

  • TypeScript + Page Objects: ações e seletores organizados por página.
  • Cucumber BDD: perfis smoke e regressão; execução por tags.
  • Execução isolada: contexto novo por cenário, navegador selecionável e evidências de tela/vídeo.
  • GitHub Actions: Node 20, verificação de tipos, smoke e relatórios como artefatos.

AUTOMAÇÃO DE TESTES · CYPRESS ↗ PESSOAL

Musi Cypress E2E

Uma segunda suíte, independente da implementação com Playwright, que usa Cypress para testar os formulários de cadastro e login da Musi e conferir o comportamento responsivo em diferentes telas.

JavaScript Cypress Testes E2E GitHub Actions

COMO O CYPRESS FOI CONFIGURADO

  • Configuração central: URL do ambiente por variável, viewport padrão e timeout definido.
  • Execução estável: nova tentativa em CI e limpeza de cookies/storage entre testes.
  • Responsividade: validação de overflow e campos em mobile, tablet e desktop.
  • GitHub Actions: Cypress em push, pull request e execução manual; vídeos e screenshots arquivados.
