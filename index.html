BACK-END HTTP · ROBOT FRAMEWORK ↗ PESSOAL

Musi Robot HTTP Smoke

Uma terceira suíte que valida, por HTTP e sem alterar dados, a disponibilidade e o conteúdo das rotas públicas de login e cadastro. Complementa os testes de interface com uma checagem direta das respostas do servidor.

Python Robot Framework RequestsLibrary GitHub Actions

COMO O ROBOT FRAMEWORK FOI CONFIGURADO

  • Page Object para HTTP: um resource reutilizável encapsula sessão, rotas e validações.
  • RequestsLibrary: confere status HTTP, tipo HTML e título esperado das páginas públicas.
  • Execução segura: somente GET em /login e /register; sem login, POST ou criação de dados.
  • GitHub Actions: Python 3.13, dependências fixadas e relatórios Robot publicados como artefatos.
  • Relatórios: report.html, log.html e output.xml em robot-results/.
